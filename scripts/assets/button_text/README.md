# 小米 15 按钮字形模板

四个 160×40 的灰度模板仅保存按钮主行的白色字形。识别器从最新画面提取同尺寸字形，匹配通过就释放首击。已校准的字形如下。

| 模板 | 文案 | 用途 |
| --- | --- | --- |
| `buy_now.png` | 立即购票 | 最初标定的购票字形 |
| `book_now_first.png` | 立即预订 | 澳门场刚开售的第一帧 |
| `book_now_stable.png` | 立即预订 | 同场动画结束后的字形 |
| `buy_now_xuezhiqian.png` | 立即购票 | 薛之谦无锡场出现的购票字形 |

澳门场的首帧与稳定帧差异超过 0.04 的匹配阈值，因此单独标定。无锡场的购票字形也超过原购票模板的阈值。未知字形交给 OCR 识别。

在仓库根目录运行 `.venv-phone/bin/python -m unittest discover -s tools -p 'test_button*.py'`。通用测试用这些字形合成按钮，验证图像提取、四种模板的首次匹配和相似负样本的拒绝。保留了历史画面的机器还会执行原始帧回放，包含澳门和无锡两场共 239 帧，以及此前标定的「立即购票」独立样本。截图和原始回放数据保存在本机。
